# 🎵 Sistema Musical

Projeto desenvolvido para gerenciar artistas e músicas.

## Funcionalidades
- Login no sistema.
- Cadastro de artistas.
- Cadastro de músicas.
- Listagem de músicas.
- Filtros de pesquisa.

## Tecnologias utilizadas
- HTML
- CSS

## Como acessar
Abra o arquivo `login.html` no navegador.
